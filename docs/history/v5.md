# Tracker + voice companion v5 (Nov 13, 2026)

Nothing touches the game: F9/F10 only listen, OCR only reads the screen, and the wiki lookups only read poewiki.net and poedb.tw. Your data comes over by itself the first time v5 opens, and nothing is lost.

## 1. Importing: one way in, and it's PoB
- **Import PoB build** is the gold button at the top of the page (there's another at the top of Links & tree). It opens the import box with the cursor already in it.
- It takes a PoB export code, a pobb.in or poe.ninja/pob link, or the .xml file PoB saves (Documents\Path of Building\Builds). You can paste the code or link, pick the file with **Choose .xml file…**, or drop the .xml anywhere on Links & tree or Character.
- **The JSON imports are gone:** Import profile, Import log, Import triggers and Load build config. You set everything except the build in the panels (pace, chase list, drop & event types).
- **Download backup** (header) saves one .json with everything: log, characters, build, chase list, wiki links and settings.
- **Restore backup** is under **Character → Advanced**. It takes that backup, and an old v4 profile file still works too. It's the only place that reads JSON.
- **Every button says what it does, and its tooltip names the file type.** If you give it the wrong thing, a plain message tells you where it goes. For example, a .xml dropped on Restore says "use Import PoB build", and an old build-config .json says "import the PoB itself".
- Old trigger files are no longer read; the tracker uses its built-in triggers. If one is still loaded from an older version, Advanced shows **Use built-in triggers**.

## 2. Pace target
- Campaign pace now has a **Target** row:
  - **League start** (≈6–8 h, the old plan)
  - **Alt character** (≈3.5–4.5 h)
  - **Speedrun** (≈2–3 h)
  - **Custom**
- Custom takes your own time to A10 Kitava (4, 4.5, 4:30 or 270m). Every act scales in proportion. Under **Per-act minutes** you can fix any checkpoint, and the others share whatever time is left.
- The ahead/behind boxes, the "Compare to" buttons, the milestone table, Next up and the voice answers all follow the target. For example, on Alt the boxes read "3h26 stretch / 4h realistic / 4h34 fallback". The time budget for each stop shrinks with faster targets too.
- **Voice:** "set pace alt", "set pace league start", "speedrun pace", "pace target 4 hours", "pace target 4:30". "Undo" puts the old target back.
- The target is saved, and every character uses it until you change it.

## 3. Text size
- The header has **A− 100% A+**, which sizes the whole page from 90% to 150%. Click the % to go back to 100%. Your setting is saved.
- **Small notes are bigger now.** The smallest notes (like the Chance/Uniques note in Power Chase) went from 11 px to 12.5 px at 100%, and badges went from 11 px to 12 px. Chase notes are 13 px.
- At 125% and above, the panels use fewer, wider columns, and Links & tree moves to full width at the bottom so nothing gets squeezed.
- **Voice:** "bigger text", "smaller text", "text size 125", "reset text size".

## 4. Power Chase colours, groups and filter
- Every content type has a colour, shown on its chip, its group and each item:
  - Abyss: dark green
  - Legion: deep purple
  - Breach: purply red
  - Delve: azurite blue-teal
  - Settlers/Kingsmarch: gold
  - Atlas Boss: crimson
  - Crafting: steel grey
  - Expedition: rust
  - Ritual: blood orange
  - Harvest: leaf green
  - Heist: indigo
  - Blight: olive
  - Essence: cyan
  - Delirium: mist white
  - Ultimatum: amber
  - Sanctum: rose
  - Incursion: temple orange
  - Bestiary: brown
  - Betrayal: slate
  - Maps: map blue
  - Other: neutral grey
- Your own types get a steady colour of their own until you pick one.
- New content types were added once: Delirium, Ultimatum, Sanctum, Incursion, Bestiary and Maps.
- **Filter chips** at the top: tap Abyss to see only what you're watching for in Abyss, with a "Farming Abyss: watch for …" line. Tap it again to see everything.
- **Group by content type** is a checkbox. With it off you get one flat list with coloured chips.
- **"Also from":** an item can list other content that drops it. The abyss jewel now also lists Delve, so it shows up in both.
- **Content types & colours** lets you add your own type with a colour, recolour any type (↺ resets it) and delete types.
- **Voice:** "what am I watching for in abyss", "chase for delve", "I'm going to farm legion, what am I watching for". The panel filters to that type and the companion reads the open items out loud.

## 5. Panels you can move
- Drag any panel by its title, or by the ⠿ handle, to any place in any column. The other panels make room while you drag. Near the top or bottom of the window the page scrolls by itself. Esc cancels the drag.
- The layout is saved.
- **Collapse:** ▾ on each panel collapses it down to its title.
- **Panels menu** (header):
  - Show or hide each panel.
  - Move panels with ▲▼◀▶.
  - **Reset layout** puts everything back and shows every panel.
- **Keyboard:** tab to a panel's ⠿ handle and use the arrow keys.
- If a panel is hidden or collapsed, saying a command for it (for example "Import PoB build") opens it again.

## 6. "Get wiki link for X"
- Say "get wiki link for Darkness Enthroned" (or "wiki link for the dark monarch", or "poedb link for …").
- The companion searches poewiki with the same name check as research, so "the white death" won't turn into "Death". If poewiki has no page, it tries poedb.
- It copies the link to the Windows clipboard (with Windows' own `clip`) and says "Wiki link for Darkness Enthroned copied."
- It does **not** log a drop any more.
- **The new Wiki links panel:**
  - Lists your recent links, newest first, kept across restarts (up to 40).
  - Each link opens in a new tab and has a **Copy** button (browser clipboard).
  - **Clear list** empties it.
  - You can also type a name in the panel's box.
- Research answers keep their wiki link, and the page they used also lands in Wiki links.
- To turn off the clipboard copy, add `"copy_wiki_links": false` to `voice\config.json`.

## 7. "Get a 6 link" is not Act 6
- When importing a PoB, a number now only counts as an act if it comes right after "Act" or "A" ("Act 6", "act6", "A6", "Act 4-10", "A1-A3"). "Get a 6 link", "5L chest", "6 socket" and "level 6" never become acts.
- Your PoB imports the same as before: "Early Rare 6 link {1}" is an Early-maps set, and Act 4-10 covers A4 to A10.
- By voice, "get a 6 link" logs a 6-link drop, and the act stays where it was. Regression tests cover both.

## Small fixes
- A lookup that found nothing could leak its cleaned-up name into the next lookup's "not found" message and poedb try. Each lookup now starts clean.
- When the tracker tab isn't open, the companion's fallback now describes pace and text commands properly ("pace target alt", "text bigger").

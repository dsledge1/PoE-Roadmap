# Tracker + voice companion v4 (Nov 12, 2026)

Nothing touches the game client: F9/F10 stay listen-only, OCR only reads the screen.

## Drop & event types you can edit (per character)
- **Log manually · drop & event types** (in Drops & events): add, rename, delete, change the kind (drop/event) and edit the spoken aliases. The quick-click buttons are gone; there's a compact manual box with autocomplete instead.
- Defaults (19): 4-link, 5-link, 6-link, 6-socket, "3/4-link, right colours", Unique (by name), Fate card, Viscera, plus the built-in events (Death, Near death, Reached T1/T6/T11/T15, Reached level 68, Atlas opened, Second map-device slot, Verisium Outcrop found, Frostbearer captured). Built-in events (★) keep their effect, e.g. a death marks the character dead.
- Voice: "add drop type mirror shard", "add event type boss down", "delete drop type …", "rename drop type X to Y". Undo works.
- "Dropped a 4 link" → 4-link, "found a 5 link" → 5-link, "got a 6 socket" → 6-socket, "4 link with the right colours" → 3/4-link, right colours.
- Questions and hypotheticals never log ("is a 6 socket worth it?", "if I find a 6 link…").
- A new character copies the previous character's types. **Defaults** resets them.

## Layout
- Next Up now sits above Voice. Each panel is in a registry (`data-panel`, `src/layout.js`) so it's ready for drag-and-drop later. No DnD yet.

## Sharing with other players
- **Use my own PoB** (Links & tree): opens the import box with the cursor in it. It takes a PoB code, a pobb.in / poe.ninja link or the XML.
- **Export profile / Import profile** (Character): one JSON file with the build config, drop/event types, Power Chase list and content types. No log, no history.
- **Start fresh for another player**: asks twice, then wipes this browser's tracker data. You get the default demo build and empty lists, with nothing of the author's (log, characters, voice history, chase, custom types).
- README: a "For other players" section.

## Fate boss voice command
- "Fate boss Merveil", "fate boss: Brutus", "What's the Fate boss effect for Merveil?", "Pull up the Fate boss from Merveil", "fate boss for X", "what does X give", "fate reward X", "show me X fate". Fuzzy match ("mervail", "malakai"). The tracker opens the entry, scrolls to it, highlights it, and says a short summary: "Merveil, Act 1, The Cavern of Anger. Siren's Tentacle: …".

## Power Chase panel
- Off during the campaign. Turn it on with **Enable when maps and res are good**.
- A checklist per character: item, content type, note, done. Grouped by content type, with a filter. Add, edit, delete and tick in the UI.
- Content types are editable (Delve, Legion, Atlas Boss, Abyss, Settlers/Kingsmarch, Crafting, Expedition, …).
- Templates: Spectre Necromancer (+1 Spectre chest from Delve, "Dread boss fight" from Atlas Boss for Incarnation of Dread, which drops Bonemeld and The Dark Monarch, +1/+1 wand from Crafting, Darkness Enthroned from Abyss, an abyss jewel from Abyss, Frostbearers from Settlers) and ED Occultist (adds Timeless jewel → Legion).
- Voice: "chase done Darkness Enthroned", "add chase item Shavronne's Wrappings from Delve", "what's left on my chase".

## Fixes from the author's live v3 session (23:06–23:22 ET; each line is a regression test)
1. Follow-ups like "Main attack links only." / "just the movement" within 60 s of a links question filter the last answer.
2. All the Fate boss phrasings above open the entry and read it out.
3. News/X/Twitter/Reddit questions: trailing filler ("if there's any new information") is stripped. The reply says it only checks poewiki and poedb, can't read X/Twitter/Reddit, and suggests asking the planning chat assistant in chat. "Twitter" no longer triggers a wiki lookup.
4. Research tries the full phrase first and strips lead-ins ("map for", "database for", "poedb for", "map is"). A weak partial match ("White Death" → the Death card) is rejected with "I couldn't find a page for '…'" and the closest titles. Unknown questions offer "Want me to look that up? Say yes"; a "yes" within 20 s runs it. Research is still not the default.
5. The Cane of Kulemak answer is verified: the variant page lists Catarina, Master of Undeath. Item-acquisition variant pages are now read, and the prompt insists on the fetched text only ("the page doesn't say …" otherwise).
6. OCR: the first F10 was on the **Offence** tab. That's now detected (accuracy, attacks/sec, crit, DPS, no resistance labels) and the reply is "That's the Offence tab, open Defences and press F10 again." with no confirm. Under 4 Defences fields: "That read looks incomplete …" before any confirm. Auto mode falls back to rapidocr under 6 fields, and rapidocr is pre-warmed at startup (cold 8 s first read before; warm ≈0.3 s on the box).
7. An empty recording or a very short press at session start just beeps ("Didn't catch that" is gone) and is logged.
